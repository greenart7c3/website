# Amber, Citrine & Morganite

Landing page for three open-source Nostr Android apps from
[`greenart7c3`](https://github.com/greenart7c3):

- **Amber** — a Nostr event signer (NIP-46 / NIP-55).
- **Citrine** — a local Nostr relay that runs on your phone.
- **Morganite** — a Blossom media server (BUD-01) that hosts your files on your phone.

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production bundle is written to `dist/`.
